# Sales Analytics Dashboard

A modular Streamlit skeleton app for sales analytics.

## Project Structure

- `app.py` - Main Streamlit app with sidebar navigation
- `data/sample_sales.csv` - Sample sales dataset
- `utils/loader.py` - CSV loading and cleaning utilities
- `utils/charts.py` - Plotly Express chart helper functions
- `requirements.txt` - Python dependencies

## Run Locally

1. Install dependencies:
   `pip install -r requirements.txt`
2. Start the app:
   `streamlit run app.py`

## Notes

This is the initial skeleton. Only the Overview page metrics are implemented.
